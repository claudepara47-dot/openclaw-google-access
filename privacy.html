Personal integration · Privacy policy

How this integration uses data

Effective date: 8 November 2026. This policy describes the personal OpenClaw Google integration operated by claudepara47-dot.

Data accessed

With the account owner’s authorization, the integration can access Google account identity information, Calendar calendars and events, and Drive file metadata and file contents. The granted Calendar and Drive scopes permit reading, creating, editing and deleting resources, subject to the account’s permissions.

Purpose and processing

Access is used to carry out the owner’s requests, such as answering questions about events, managing appointments, finding documents and managing files. OAuth credentials and refresh tokens support authenticated access and automatic token renewal.

Storage and retention

OAuth credentials are stored on the operator’s device using gogcli’s encrypted file keyring, protected by local file permissions. A local password file permits unattended use. OpenClaw conversation history, logs, downloaded files and generated results may also remain on the operator’s device until the operator removes them. Google continues to store the original cloud resources under its own policies.

Services receiving data

The integration communicates with Google APIs. Request text and relevant retrieved data may be sent to the assistant’s configured model provider, currently DeepSeek, to process the owner’s request. When the owner interacts through Weixin, request and response content passes through that messaging service. These services apply their own privacy and retention policies. The operator does not sell Google user data or use it for advertising.

The operator uses Google user data only for the requested personal assistant functions, not to train generalized AI or machine-learning models. Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Revocation and deletion

The owner can revoke access in Google Account connections and remove the locally stored account credentials through gogcli. Revocation stops future authorized access; it does not by itself erase prior local logs, conversations, downloaded files or data already processed by a service. Those records must be removed separately using the relevant application or service controls.

This website

This static website has no sign-in form, analytics scripts or Google account access. It is hosted by GitHub Pages. GitHub may process technical request information under the GitHub Privacy Statement.

Contact and changes

Contact the operator through their GitHub profile. This policy will be updated if the integration’s data practices change.
